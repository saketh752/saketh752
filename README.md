## 🚀 Featured Build: AI Fitness Platform

<div align="center">

[![Repository](https://img.shields.io/badge/GitHub_Repository-saketh752%2FAI__Fitness__Platform-black?style=for-the-badge&logo=github)](https://github.com/saketh752/AI_Fitness_Platform)

</div>

**[AI Fitness Platform](https://github.com/saketh752/AI_Fitness_Platform)** is a multi-tier health and athletic coaching ecosystem designed and implemented around a polyglot microservices architecture:

- **Mobile Client**: Flutter application for video feed ingestion, workout tracking, and interactive user flows.
- **Business Core Backend**: Java 21 and Spring Boot handling JWT authentication, workout scheduling, profile state, and API routing.
- **Computer Vision Service**: Python / FastAPI microservice leveraging Google MediaPipe for landmark coordinate extraction and joint kinematics.
- **AI Coaching Service**: Python / FastAPI microservice integrating Groq Cloud (Llama 3) for contextual feedback with automated safety intercepts.
- **Persistence & Migrations**: MySQL with version-controlled Flyway schema migrations.
- **Infrastructure**: Containerized with Docker Compose multi-service networks.
